# Pixelarticons subset

26 selected icons from [Pixelarticons](https://github.com/halfmage/pixelarticons), an MIT-licensed set with a [Figma Community file](https://www.figma.com/community/file/952542622393317653).

Source revision: `c9ecc2da61afde85dbe539025e3d931c6152ad75`. Each SVG was verified against the upstream Git blob before its paths were combined into the local sprite. Icon IDs match the original filenames under `svg/`:

`upload`, `plus`, `arrow-right`, `refresh`, `pencil`, `copy`, `login`, `download`, `trash`, `arrow-left`, `minus`, `scale`, `close`, `undo`, `arrow-bar-up`, `arrow-bar-down`, `lock`, `colors-swatch`, `link`, `expand`, `collapse`, `arrow-bar-right`, `arrow-bar-left`, `image`, `user`, `map-pin`.

`pixelarticons.svg` contains only these icons. The app references its symbols directly, inherits colours through `currentColor`, and loads no icon package, font, CDN or runtime library. Use at 24 px for alignment with the source grid. Copyright and permission terms are preserved in [LICENSE.txt](LICENSE.txt).
