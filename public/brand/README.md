# Wilderness Almanac branding

`wilderness-antler-mark.svg` is the active mark, covered by [AGPLv3](../../LICENSE).
The menu uses its `antler-mark` path; favicons use the same artwork.

Regenerate favicons with `python3 tools/render-brand-icons.py`.
Requires `rsvg-convert` and Pillow.

The footer reuses the landing page's `figma-mark-bordered.svg` and
`figma-wordmark.svg` unchanged. CSS masks apply the current accent colour.
The artwork retains AGPLv3; the Geist Pixel Square lettering retains its
[SIL OFL attribution](../fonts/README.md).
